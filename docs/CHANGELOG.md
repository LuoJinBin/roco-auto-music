# 更新记录

## 1.2.0-alpha.2

- 曲库默认显示 7 行，拖动列表底部可调整高度，重开会恢复。播放控制固定在窗口底部。
- 在线 MIDI 和本地 MIDI 超出游戏音域时，可直接在工具里选择“适配九键并载入”。保留起音时间并提示改动音符数。
- 仓库首页和发布说明提供建议与 Bug 反馈入口。

本版已构建安装包与便携包。界面操作、安装升级和游戏奏乐尚未实测。

## 1.2.0-alpha.1

- 增加无需自建后端的 GitHub Releases 更新：检查版本、稳定/预发布通道、更新说明、下载进度、SHA-256 校验，确认后退出并启动安装器。
- 天空与草地主题、手碟装饰、三步就绪提示、悬停说明和使用帮助。
- 超范围曲谱改为处理指引，提供九键曲库筛选、原曲网页、转谱说明和可展开的音符详情。
- 载入新曲失败后清空旧曲，避免误奏上一次选择的歌曲。
- 更新和安装不自动演奏、安装驱动或重启。

本版未运行功能测试、更新安装测试或奏乐测试；构建与截图不代表运行验收。
