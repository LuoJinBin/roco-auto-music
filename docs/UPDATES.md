# 不用自建后端的更新

## 玩家怎么用

1. 右上角点击“检查更新”，再点窗口中的检查按钮。
2. 有新版时显示版本号和发布说明；点击“下载新版”。
3. 文件完整下载并通过 SHA-256 核对后，按钮变成“退出并安装”。
4. 确认后工具释放按键并退出，随后打开安装向导。安装完自己启动工具，不会自动奏乐。

更新窗口打开时演奏暂停，关闭后不会自动继续。可取消下载，未完成文件会清理。正常退出也会发出取消信号；网络读取最长可能等到超时才结束。

安装版沿用当前安装目录。便携版用户可以安装新版，也可以到发布页下载新版 ZIP 后解压；此功能不在便携文件夹里自动替换 EXE。配置、缓存与日志仍在 `%LOCALAPPDATA%\RocoAutoMusic`，更新安装不清除此目录。更新不安装系统驱动、不重启电脑、不修改 PowerShell 执行策略。

旧版 1.1 没有更新入口，需要先手动安装一次 1.2 或更高版本。

## 设置

- 启动检查默认关闭，打开后只查询版本和显示提示，不自动下载或弹出安装向导。
- 正式版默认仅看稳定通道；本次开发版默认包含预发布，可自行关闭。
- 预发布版可能存在未经验证的问题；安装前请阅读发布说明。
- 偏好保存在本地 `settings.json`，不需要账号。

## 发布者怎么发新版

1. 更新 `rocomusic/version.py` 的版本和 `docs/CHANGELOG.md`；版本格式为 `X.Y.Z` 或 `X.Y.Z-alpha.N/beta.N/rc.N`。
2. 构建 EXE，再使用 `tools/build_release.py` 生成安装包和便携 ZIP。安装器从脚本接收同一版本号。
3. 创建同版本 GitHub Release，例如 `v1.2.0-alpha.1`；开发版本标记为 prerelease。
4. 上传精确命名的 `RocoAutoMusic-Setup-1.2.0-alpha.1-x64.exe`、便携 ZIP、对应项目源码、Interception 对应源码及 `SHA256SUMS.txt`，资产齐全后公开。
5. `SHA256SUMS.txt` 使用 UTF-8，每行 `64位SHA256  文件名`（两个空格）。安装包必须恰好对应一条记录。若 GitHub 提供资产 digest，也必须与清单一致。

更新检查通过 GitHub 公共 API 读取发布列表，不需 Token，也不需要另建服务器。稳定通道使用 `/releases/latest`，预发布通道读取发布列表并比较版本；列表读取最多 500 条，超限给出明确提示。

只接受此项目的 HTTPS 发布链接以及 GitHub 已知资产 CDN 跳转，拒绝异常大小、错误 SHA-256、不完整发布和未知下载地址。SHA-256 用于验证下载内容完整性，不能代替发布者的数字签名。当前安装器尚未签名。

GitHub 明确拒绝或限流时，本次运行停止更新请求，不自动重试或更换源；可由使用者手动打开发布页。程序内没有备用镜像或代理。

官方接口依据：[GitHub Releases](https://docs.github.com/en/rest/releases/releases)、[Release assets](https://docs.github.com/en/rest/releases/assets)。

本版仅做静态审阅、构建和隔离界面截图。检查、下载、取消和安装全链路均未运行验收。
